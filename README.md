# Perfact Food Marketplace MVP

This is the official MVP repository for Perfact Food, separate from the main website.

## Deployment Target
- **Vercel Project**: `perfact-food-mvp`
- **GitHub Repo**: `mgai2025/perfact-food-mvp`

## Features
- **Buyer Marketplace**: Search, Filter, Masked Results.
- **Admin Dashboard**: Sellers, Buyers, Interests, QA, Shipments.
- **Tech Stack**: Next.js 14, Tailwind CSS, Google Sheets (optional).

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run Locally**:
   ```bash
   npm run dev
   ```
3. **Deploy to Vercel**:
   - Push to GitHub: `git push -u origin main`
   - Import in Vercel Dashboard as new project.

## Environment Variables (Optional)
See `scripts/setup-sheets.js` for Google Sheets integration.
For MVP demo, Mock Data is enabled by default.
